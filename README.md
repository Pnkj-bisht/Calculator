# JavaScript Calculator 🧮

A simple calculator built using **HTML, CSS and JavaScript**.

### Features

* Basic operations: `+`, `-`, `×`, `÷`
* `AC` button
* `DEL` button
* Keyboard input support
* Enter key for calculation
* Responsive design
* Hover effects

### Technologies

* HTML
* CSS
* JavaScript
